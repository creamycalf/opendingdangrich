# 独立命令引擎

触屏和电脑动作通过 `app/src/commands.mjs` 的 `executeCommand(map,state,command)` 执行；界面只消费返回的新状态。命令失败不会留下半次扣款、半步移动或消耗随机数后的旧对局。

命令包含开始回合、掷骰、骰子展示完成、选路/电脑选路、落点、事件推进、选择/电脑选择、使用道具和结束回合。随机选择放在命令内，动画不生成新的随机结果。

回放由格式标识 `dingdang-replay-v1`、初始存档和命令数组组成。只接受当前规则版本；失败报告具体命令序号。八张地图的完整短局与中途存档检查点都可重放至相同最终状态。

界面的内部诊断入口 `window.__game.replay()` 返回本次进入对局之后的命令记录。上限 50,000 条，达到上限后建立新检查点；不写入游戏存档，不增加玩家操作。触屏测试捕获真人和三个电脑实际产生的命令，并验证回放与当前界面状态一致。

这些检查证明引擎执行和恢复的一致性；原作规则仍必须由独立原机器码或实机证据核实。
