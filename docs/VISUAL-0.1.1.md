# 0.1.1 视觉修正

用户反馈上一版与原版差异明显。0.1.0 自行设计的顶部标题、玩家卡片、底部宽操作栏偏离了移植目标，本版撤掉这些结构。

对照图片：https://chiuinan.github.io/game/game/intro/ch/c43/doraemon/game2.png
来源页：https://chiuinan.github.io/game/game/intro/ch/c43/doraemon.htm

## 已修正

- 地图铺满游戏区域，以原作 640×480 的地图显示比例作为横屏基准；宽屏增加左右视野，竖屏允许拖动与缩放。
- 原包 sprite2.dat 的 0/1 号头像框及蓝条、178/190/201/214/218 操作图标、145–164 数字；bitmaps.dat 的 26/30 号头像。由 tools/extract_classic_ui.py 可重复提取。
- 当前玩家头像随回合切换，豆沙包显示真实试玩余额；原版图标之外的透明点击区域至少 44 CSS 像素。
- 取消彩色脚底圆盘和白色指示箭头，改为低调阴影。
- 手机竖屏操作图标排在头像上方，避免挤占计数区域。
- 道具保持灰色，点击会提示尚未实现；铃铛计数用横线表示尚未实现。

## 尚未等同原版

左下仍是本试玩实际回合数，而不是原作月份日期；铃铛、道具未实现。角色方向、完整动作、场景动画、声音、其他角色、原作经济及事件规则仍需要核实和逆向。顶部缩放辅助按钮和文字对话框属于触屏试作。当前仅为视觉修正，不宣称完整移植或逐像素一致。

原版 PC 程序未在本轮通过自动化操作验证；依据为实际原版截图和本机资源。测试覆盖浏览器移动触控及打包资源一致性，尚未经过 Android 真机测试。
