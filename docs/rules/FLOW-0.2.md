- https://github.com/lhuthng/doraemon-monopoly-localization ：地图格式与导航标记研究，本地 research/upstream-map-format.md。本机 EXE 版本不同，本轮没有将上游函数地址直接当成本机函数证据。
- https://chinesedora.com/database/ding-dong-rich.htm ：角色特点、道具、画面规格。
- https://zh.wikipedia.org/wiki/多啦A夢大富翁 ：现金及矿山各 1000（小夫各 2000）、五级地产、使用道具代替移动、最后未破产者获胜。社区资料，不是原版说明书。
- https://acgvn.com/game/doraemon-monopoly/ ：人数不足四人由电脑补足，初始资金对照。

## 已接通

主菜单 → 四名角色及真人/电脑选择 → 开局 → 回合开始/休息 → 掷骰或道具 → 移动/选路 → 付租 → 落点事件 → 相邻地点选择 → 购买/升级/矿山/商店 → 下一玩家 → 破产/胜负结算 → 再玩或返回主菜单。

状态：ready / moving / resolving / landed / prompt / end / gameover。选择参数和待执行事件队列随存档保存。移动先提交并存档再播放动画，防止重复走格、扣费。暂停、返回主菜单会中止旧控制器继续推进。

默认一人三电脑，可选四真人和六名常规角色。30/60/120 天短局是手机版新增选项，到期按现金、存款与地产投入原值合计排名，允许并列。

有资料支持：初始资金、五级建筑；哆啦A梦每格吃一个豆沙包、胖虎最多四步、静香周日休息、大雄每月空气枪且不能攻击静香；矿山存取款、商店、用道具后不掷骰、仙人三选一和护身符。

地价读取原地图 price 原值，取消旧版乘 100；运行时是否还有原版倍率待核实。六名角色四方向素材直接提取，时序、锚点仍为当前实现。

## 未核实的具体规则

| 项目 | 本版实现 |
| --- | --- |
| 地产交互 | 经过道路时向相邻敌方地产付租，同一地产每次掷骰只收一次；落点可选一处相邻土地或设施 |
| 租金 | 地价 × [0.1,0.3,0.8,1.5,3]，向上取整，最低 1 |
| 升级 | 地价 × (当前零起算等级 + 2)，共四次升级 |
| 出售 | 地价与升级投入总额的一半，向下取整 |
| 欠款 | 可紧急取矿山存款并卖地；总变现资产不足才破产，余额付债权方，地产清空 |
| 日期 | 开局使用设备当天日期，全员一轮过一天；额外行动不推进日期 |
| 胖虎相遇 | 10 个豆沙包，向其他人收取时不超过其现金 |
| 奖励/罚款 | 各 50；罚款进入奖金池 |
| 炸弹 | 100 到奖金池，并休息一回合 |
| 宝箱 | 好箱奖励 150，坏箱罚 75；结果提前保存，不随读档重抽 |
| 大事件 | 平分在场角色现金，余数按玩家序分配；矿山存款不变 |
| 道具价格 | 任意门 180、空气枪 100、护身符 80；口袋上限 12 |
| 任意门 | 传送至主地图普通道路并处理落点，不处理沿途租金 |
| 空气枪 | 使一名对手休息一回合；未还原原版全部距离、命中、保护判断 |
| 初始道具 | 哆啦A梦/哆啦美持任意门和护身符，仅对应当前开放子集 |
| AI | 独立实现选路、经营、存取款、购买/使用空气枪、宝箱与偿债策略 |

倒霉区域：本机配置候选入口 (17,18)，普通导航中与主路分离；(23,18) 是事件 11、flags 0xc5 的出口。允许区域内玩家通过出口，正常玩家不能反向进入；每次移动 1～3 格直至离开。这是原数据几何及流程需求的推断，尚未追踪本机 EXE 的确切出口函数。已测试入口、穿过出口、中途读档和重回主路。
