# 商店供货、买价与卖价

证据源为本机原版 `wa.exe`，SHA-256 为 `f190b35370d3efe3024b5105a90f85abf07f5915e7b7a431d93b756de03f65f3`。不需要运行 Windows 游戏界面。

## 已确认的行为

每店记录 348 字节：三个坐标整数，随后 42 项买入基价和 42 项卖出基价。`0x47f87d` 按坐标取记录，真人商店对象由 `0x4a3950` 创建。

- `0x4a3c59..0x4a3c91`：买入基价为零的道具不列入供货，不是免费。
- `0x4a45c3..0x4a45fb`：买价 = float32(买入基价 × float32(物价倍率) × float32(购买百分比) / 100)。中间运算留在 x87 中，只有最终金额存为 float32。
- `0x4a4657..0x4a4666`：以负数传给玩家金钱增减方法；不是先把显示值截为整数再扣款。
- `0x4a4945..0x4a4977`：卖价 = float32(卖出基价 × float32(物价倍率))，不应用购买百分比。
- `0x4a4977..0x4a49b1`：金钱增加后，相应道具数量减少一件。即使本店不供货，也可以卖出已持有的道具。
- `0x4c54bc` 是物价倍率；`0x4c55e0` 是购买百分比，初始化为 100，存在改为 60 的代码路径。触发和恢复时机尚未接入。

小镇第一家商店：任意门买 80 / 卖 40，护身符买 80 / 卖 40，空气枪不供货 / 卖 100。以前的固定 180 / 100 / 80 买价已移除。

## 对照与接入

`tools/verify_original_shop.py` 使用 Unicorn 执行两段原始机器码，输入八张地图全部 23 家店、42 个道具、三个物价倍率和两个购买百分比。生成 5,796 组买卖金额到 `tests/fixtures/original-shop-prices.json`。`tests/shop.test.mjs` 对每个浮点数精确比较，不使用误差容限。

`app/src/shop.mjs` 提供独立价格计算和商店查找。现有道具已采用真实商店供货与价格，加入触屏出售。AI 的临时购买策略也遵守供货。所有交易走同一命令提交及存档路径；不出售的商品、没钱、没有该道具均不能改变状态。新接入的复原光线可以买卖；时间布买入基价为零，保持只回收、不出售。

规则版本为 `town-flow-4`。旧 `town-flow-2/3` 存档保留已有余额和道具，未来交易采用新价格；旧版本命令录像不能混用新规则回放。
