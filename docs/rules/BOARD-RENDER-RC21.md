# RC21：选中框围住胖虎腰部的复现与修复

2026-11-09。用户新截图 `codex-clipboard-ec6aed48-63cf-49f0-bfab-03e9335f45bb.png`。

## 先复现，再隔离

小镇地图 4，地产 825（25,16），胖虎停在相邻道路 875（25,17），P4 已购空地。
点击地产后能复现用户截图：人物腰间出现黄线菱形，旁边地基本体仍在正确格上。

`tests/ground-overlay-diagnostic.cjs` 保持资源、坐标、游戏状态和图层全部不变，
只拦截最后 `strokeStyle === '#fff1a4'` 的选中框绘制。黄框立即从胖虎腰部消失，
右边地基本体没有变化。截图为 `rc21-selection-diagnostic-before.png` / `-hidden.png`。
因此这一次的框是地图选择提示，既不是雕像，也不是角色走到了地产上。

RC20 只把空地基移到角色之前，漏掉了最末尾的 `selected` 选中框。之前五级地产
截图没有点击选中，未覆盖用户的这个触发条件。本次不再移动人物、地块或掩盖资源。

## 修复

main 的地面选择框、道具合法落点框和旧规则分支提示，在地面绘制之后、建筑及人物
绘制之前输出。选中信息、规则落点、点击判定及同一地基的坐标保持一致。
因此人物实际遮挡地面提示，地面上未被遮挡的框仍可见，地块说明仍打开。

## REA 核对原始锚点和地图分类

本次直接在 REA/Ghidra 12.1.4 打开新的 `work/new-pc-v121/Doraemon.exe`，SHA256
`b99f70be2a703b7f20e5d7dbf6d29f2ffca86303f4be420bf9fb334cbe792eb1`。
这与旧 `mapAnimationPlacement26.json` 等文件中实际指向 wa.exe 的身份不同；没有混用地址。

- `0x480db7` 与 `0x480c90`：角色/地图动画位置为 `(x-y)*40-40`、`(x+y)*20-20`，
  再减相机格偏移和高度；`0x401faa` 保存到对象 +0x50/+0x54 并加父级偏移。
  当前 `boardActorSpritePoint` 的 -40/-20 与此一致，没有再挪动角色。
- `0x47ad69`：原静态地图左边界是投影 x 减 40；静态物体 y 是投影 y 加 20 减图高。
  不是按图宽居中。地图 0/2 资源的 hx/hy 实际全部为 0；现有使用中的静态图宽 80。
  future 的未放置备用图 2-401 宽 240，也应保持 tile 左锚。本轮 `map-art.mjs` 用原式。
- 同函数以 `flags & 7 === 5` 判定背景图，以 `===7` 判定静态物体。
  `0x47e04e` 对人物前面的 class7 建筑做局部重绘，class5 不参加该遮挡。
- 原代码没有 `object < 260` 这样的类别分界。旧独立版因这个编号假设漏掉了恐龙图
  （21,17）的商店标牌：class5、object265。现在按原 class5/class7 分类绘制。
  未来图三个 class0 的对象原版也不画，未把它们误补成建筑。
- 额外移除固定 340px 的物体可见性下界，按原资源尺寸留出范围。未来地图已使用的
  2-313 高480，实际非透明像素从第32行开始；应允许基点在屏外、顶部仍在屏内的物体。
