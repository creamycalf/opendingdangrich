# 道路放置与传送

规则20纠正了任意门：它是五天道路放置物，不再即时移动施用者。沿门的通行轴穿过后重新随机取出口与朝向，继续本次移动；穿门补回一步。日期变更统一扣计时，源角色是否轮到行动不影响门的寿命。大炮13另行开放指定空闲道路传送，结束本次行动。

原二进制 SHA256 `f190b35370d3efe3024b5105a90f85abf07f5915e7b7a431d93b756de03f65f3`。REA/Ghidra12.1.4记录：

- 任意门选址 `0x49f020`，方向拒绝采样 `0x49f236`，放入道路槽和地图链表 `0x49f4f2/0x47f19c`。
- 出口 `0x49fed7`：距离平方至少10；主地图菱形严格边界；排除区域按X或Y条带拒绝；已放道路物或铃铛不能成为出口。原函数并未要求出口事件为0。
- 道路时钟 `0x47f087`，日循环调用点 `0x4747e9`，基础倒计时 `0x48dadf`。
- 大炮选址 `0x4949fe`，移动/朝向 `0x494b35`。目标无角色、道路物、铃铛；保留可行原朝向，否则随机重抽可行朝向。
- 门图像来自 Tools.dat 47/48 的最后一帧，引用 Sprite1.dat；世界定位 `0x47fe57`，保留原偏移。

`tools/verify_original_road_items.py`执行八图1171个地点及每地占位/邻格变化，192条出口轨迹（含大量道路占位），由 `tests/road-items.test.mjs` 对照。手机浏览器验证取消、占用位置拒绝、选点、保存续玩和精确回放；规则20安卓验证另记。

边界：尚未接入的铃铛、缩形隧道、分身等对象不在当前局面中生成。复杂动态道路互动仍需在这些系统接入时继续对照。当前门的侧面选路采用禁止侧入、无路时回头；尚未逐帧复制原连续移动控制器的所有转向分支。传送动画尚未完整播放。此记录不把这些缺口算作已完成。
