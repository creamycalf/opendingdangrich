# v1.26 矿山比例存取

原件 SHA256 b99f70be2a703b7f20e5d7dbf6d29f2ffca86303f4be420bf9fb334cbe792eb1。
矿山入口是 0x4453a7，旧版本 0x4450e5 的地址不能直接套用。
REA 原始记录保存在 research/v126-bank-0x4453a7.json、0x403812、0x403a96、0x403c6c 对应文件。

0x403812 初始化滑条为50，载入 bitmaps.dat 124号矿洞及125号把手。
0x403a96 每次左右输入调整1档，范围0至100。确认提交预览余额，取消维持原余额。
0x403d7a 以50为中点，每档存入当前现金的2%，或取出当前矿山余额的2%。
交易金额保留float32小数，显示时截断。0x4453a7 在新旧现金截断值相同的情况下直接退出。
因此界面改为同一比例滑条，可全存、全取和每2%调整；移除先前固定100与半额按钮。

tools/verify_v126_bank.py 隔离执行 0x403d7a 至0x403e48，5组余额覆盖101档，共505组与移植函数匹配。
tests/bank-amount-ui.cjs 在915×412、640×320、360×640验证比例预览、确认、无滚动溢出和冷载后资金保持。
手机呈现保留原矿洞及把手素材，采用适合横竖屏的布局；尚未验证原GUI滑条视觉位置及转账动画逐帧一致。
