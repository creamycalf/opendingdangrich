# RC20 地产贴图、道路朝向与地面说明

2026-11-09，针对用户的未来世界地产黑剪影、空地基压住人物和铜锣烧圈含义反馈。

## 确定根因

旧绘制把小镇地图地产 terrain 32 当成八图共同基址：
`(terrain-32+4)%4`。实际各图地皮族不同；未来世界为 13～16。
JavaScript 负数余数使 terrain 13 得到方向 -3。P4 地产由 0 升到 1 时，
旧公式选到 `1-3+3*57=169`，属于 P3 资源块末端的原始黑色占位人像，
而不是 P4 铃铛地基。不是图片解码或需要换掉原图：1824 张地产原 PNG 与
图集裁片逐像素一致。

原版地图地皮编号本身不决定朝向。当前实现改为原程序的道路判定。

## 原程序证据与独立执行

文件 `work/new-pc-v121/Doraemon.exe`，SHA256
`b99f70be2a703b7f20e5d7dbf6d29f2ffca86303f4be420bf9fb334cbe792eb1`。

- `0x4431eb..0x443204`：升级前按地产坐标调用 `0x47edd1`，保存朝向。
- `0x47edd1..0x47f077`：读取四邻道路；唯一道路直接采用其方向；多方向时比较
  两轴到道路之间的非道路跨度，选择轴后按北、南、西、东取首个方向。
- `0x47b800..0x47b8f7`：原始道路查询，检查地图边界、实际层、flags 的 0x80/
  0x40 和运行时阻挡对象。
- `0x443278..0x4432e0`：每玩家 57 张；等级 1～3 采用 `1+(level-1)*4+direction`；
  等级 4 采用 `13+character*4+direction`；再加玩家块偏移。

`tools/verify_property_art.py` 用 Unicorn 执行原版上述朝向函数及真实道路查询，
无函数桩、无操作系统启动；载入八张真实地图，并使用空闲运行时道路对象槽。
输出 `tests/fixtures/original-property-art.json` 的 497 个地产，全部方向为 0～3。
`property-art.mjs` 与该独立输出 497 项逐项相等。普通建筑不会再依赖 terrain。
测试另穷举 497 地产 × 4 玩家 × 7 角色 × 5 等级（69580 组合），检查存在资源且
始终落在正确玩家、等级、角色图块族，包含黄耳叮当。

## 图层和地格说明

空地基属于平面，改为与道路图标一起画在角色之前，避免其按前景排序覆盖人物。
升级后的建筑仍使用同一世界坐标和纵深排序。保留原角色脚底锚点，不挪动规则落点。
胖虎四级地产原图是金色雕像；用户图中的橙色胖虎是人物，不用改图伪装重叠问题。

原图 `2-241..244` 红底铜锣烧对应 event 10（奖励圈），`2-245..248` 黑底铜锣烧
对应 event 11（征罚圈）。点击现在显示现有规则的具体效果：全局 50～450 奖励循环；
基础 75～149 乘物价的罚款、计入奖金池及道具免罚。其余事件地格也有实际效果说明。
