# 八张地图会话接入

当前源码 0.3.0-dev，未作为完整版交付。

- 设置页面提供八张地图及原作内置预览。中文显示名称按已知主题命名，不宣称全部与原版菜单文案一致。
- 新游戏按选择的地图读取出生点、方向、地产值和倒霉区域坐标；不再复用小镇坐标。
- 地图图片先全部加载到临时集合，确认成功后才切换当前地图并写存档。资源失败保留原图、原存档，恢复设置按钮。
- 继续游戏按存档中的地图编号加载相应资源，再验证存档；拒绝 0～7 以外的编号。
- 换图清理选择框、移动插值和手势，保留角色公共图片；全图及拖动边界按实际地图尺寸计算，覆盖 40×40 至 80×80。
- `tests/maps-ui.cjs` 验证八图创建、浏览器重新加载后继续、掷骰，以及资源加载失败时原存档不被覆盖。结果为 `test-results/maps-ui-report.json`，截图为 `test-results/map-*-overview.png`。
- 核心测试遍历八图完成 30 天对局，期间周期性序列化/恢复；只证明当前实现无该类流程死锁，不证明其经济和特殊事件与原版一致。

仍待完成：地图特有角色/动画/事件、游戏室、道具与音效、动态占用、特殊道路、地产朝向的跨地图核对、原作剩余经济与事件规则、安卓实际运行。

验证入口为 npm test、tests/flow-ui.cjs 与 tests/maps-ui.cjs；最新数量见各测试报告。八图创建/恢复/掷骰及失败恢复检查通过，TypeScript/Vite 构建成功。此次没有覆盖或生成新的 APK。
