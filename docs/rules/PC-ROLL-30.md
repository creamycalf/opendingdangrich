# 原版步数演出追踪

新版 EXE SHA256 b99f70be2a703b7f20e5d7dbf6d29f2ffca86303f4be420bf9fb334cbe792eb1，Ghidra 12.1.4。原始证据 research/v121-roll-0x43c8eb.json、0x439744.json、0x47e2d4.json。

0x43c8eb 的上限来自玩家 +0x128，倒霉区域为3。它载入 sprite2[2,75..78]，循环计算各个步数的可达终点，绘制蓝色整格/半格标记，并交替播放77/78号音效。0x439744递归枚举终点，限制反向和连续转弯。interface[3..5]在0x47c572用于地图选点，interface[6]在0x474525用于日历时钟，均不是骰面。

当前改动：移除字体骰面与误用标题语音，显示数字提示及原版蓝色落点素材；播放77/78音效。保持移动端已保存的点数和随机种子，演出结束才放行移动。半格标记按方向和坐标奇偶选择。

限制：移动端演出时间仍为适配值，未复现PC随机减速算法；数字提示为触屏辅助。标记是地形可达终点，不预测任意门、磁铁、途中事件导致的最终实际位置。调色板使用现有通用bitmap1，未完成全场景实机对照。这不是完整移植完成声明。
