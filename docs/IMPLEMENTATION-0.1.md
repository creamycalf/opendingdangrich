- 通过角色调色板对照图确认 bitmaps 记录1能正常显示角色；记录0并非合适的角色调色板。此判断为视觉核验，未定位原引擎的全套调色板切换逻辑。

- 画面只加载231张当前使用图片，按可见区域绘制；提取文件共约1.5MB。尚未进行低端真机内存与帧率测量。
- 当前处理静态场景和事件地面图片；动画触发/组合记录没有全部实现。

## 临时规则边界

原地图 class-1 土地在本地图全部带0xc0标记，不能直接按普通路格进入。因此临时实现为停在道路后处理正交相邻的第一块土地。
地图价格原字段与实际货币单位之间的关系尚未确认，试作版采用×100；租金10%、初始20000仅用于体验。没有将这些规则标成已逆向还原。
自由行走邻格仅按0x80允许/0x40阻止筛选，并尽量不回头；原版更细的前向判断、事件地形和方向限制尚未还原。
